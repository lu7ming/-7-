⚙️ 技术架构

核心设计

  • 单文件 HTML：~9400 行，IIFE 包裹，无框架，无后端
  • 存储：localStorage（life_data_v1 + life_settings_v1 + ai_deepseek_key）
  • PWA：Service Worker 缓存离线可用，manifest 可「添加到主屏幕」
  • 部署：GitHub Pages，git push 自动上线
  • AI：DeepSeek API（deepseek-chat 模型），OpenAI 兼容格式
  • Context 注入：collectContextData() 序列化今日/本周/目标/书籍/树/番茄/身体/提醒/购物 → 系统 prompt
  • JSON 动作协议：AI 返回 {"action":"record","type":"finance|shopping|reminder|goal|body","data":{...}} → aiHandleRecord 写入

Key 安全方案

选了 方案 C：运行时填 key。Key 不硬编码在代码里（避免 GitHub Secret Scanning 拦截），首次用 AI 时点「⚙ 配置 key」→ prompt() 输入 → 存 localStorage → 刷新不丢失。

📖 使用指南

首次使用

  1. 打开 工作台
  2. 点右上角 🤖 或侧栏「AI 助手」
  3. 输入「配置 key」→ 粘贴 DeepSeek key → 回车
  4. 开始用

日常使用

  • 📱 添加到主屏幕：Safari 分享 → 添加到主屏幕 → 像 App 一样用
  • 🔄 刷新：URL 加 ?v=数字 绕过缓存
  • 💾 备份：顶栏 💾 → 导出 JSON
  • 🎨 主题/配色：顶栏 ☀️ / 🎨
  • ❄️ 休息模式：顶栏 ❄️
